agents.schemas_a2a

Agent-to-Agent (A2A) Protocol Schema.

Implements a structured message format for inter-agent communication. Every message is:

  • Typed with an intent enum (what the sender wants).
  • Correlated via a correlation_id (links request, response chains).
  • Validated on send and receive (intent must match expectations).
  • Fully JSON-serializable for logging, replay, and debugging.

Design decisions:

  • A2A was chosen over MCP because our agents are peers that exchange work products (code, test results, fix instructions) rather than a client calling a tool server. A2A's intent-based routing maps naturally to the Coder↔QA review cycle.
  • correlation_id lets us trace an entire review loop iteration as a single logical conversation even across multiple message hops.

 55# A2A Message - the core protocol record
 56class A2AMessage(BaseModel):
 57    """A single message in the A2A protocol.
 58
 59    Required fields for A2A compliance:
 60      - sender        - who sent the message
 61      - receiver      - who should process it
 62      - intent        - what the sender wants
 63      - payload       - the actual data
 64      - correlation_id - links related messages in a conversation
 65    """
 66
 67    message_id: str = Field(
 68        default_factory=lambda: uuid.uuid4().hex,
 69        description="Unique identifier for this message.",
 70    )
 71    correlation_id: str = Field(
 72        ...,
 73        description="Links all messages in a single review cycle.",
 74    )
 75    sender: AgentRole = Field(
 76        ...,
 77        description="The agent that created this message.",
 78    )
 79    receiver: AgentRole = Field(
 80        ...,
 81        description="The agent that should process this message.",
 82    )
 83    intent: A2AIntent = Field(
 84        ...,
 85        description="The purpose / action requested.",
 86    )
 87    payload: Dict[str, Any] = Field(
 88        default_factory=dict,
 89        description="Intent-specific data.",
 90    )
 91    timestamp: str = Field(
 92        default_factory=lambda: datetime.now(timezone.utc).isoformat(),
 93        description="ISO timestamp of message creation.",
 94    )
 95    parent_message_id: Optional[str] = Field(
 96        default=None,
 97        description="ID of the message this is replying to.",
 98    )
 99
100    # -- Validation --------------------------------------------------------
101    @field_validator("correlation_id")
102    @classmethod
103    def correlation_id_not_empty(cls, v: str) -> str:
104        """Validate that the correlation_id field is not empty."""
105        if not v.strip():
106            raise ValueError("correlation_id must not be empty")
107        return v
108
109    # -- Helpers -----------------------------------------------------------
110    def to_json(self) -> str:
111        """Serialize the message to a JSON string."""
112        return self.model_dump_json(indent=2)
113
114    @classmethod
115    def from_json(cls, data: str) -> "A2AMessage":
116        """Deserialize an A2AMessage from a JSON string."""
117        return cls.model_validate_json(data)

181# Intent validation helper
182VALID_INTENT_ROUTES: Dict[tuple, list] = {
183    (AgentRole.CODER, AgentRole.QA): [A2AIntent.REVIEW_REQUEST],
184    (AgentRole.QA, AgentRole.CODER): [
185        A2AIntent.FIX_INSTRUCTIONS,
186        A2AIntent.ALL_TESTS_PASSED,
187        A2AIntent.MAX_ITERATIONS_REACHED,
188    ],
189}

192def validate_message_route(message: A2AMessage) -> bool:
193    """Check that the intent is valid for the sender,receiver pair."""
194    route = (message.sender, message.receiver)
195    allowed = VALID_INTENT_ROUTES.get(route, [])
196    return message.intent in allowed
